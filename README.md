# 一念星河

治愈系宇宙卜卦小程序 MVP。

用户在深邃星空中轻触屏幕，触发星尘涟漪与聚拢动效，随后浮现一张“宇宙之卡”。卡片通过八卦、五行、天象、烦恼主题、答案倾向、签语和今日宜组合生成，提供温柔、诗意、非恐吓式的情绪陪伴。

## 项目内容

- `pages/index/`：微信小程序主页面
- `index.html`：同体验的 Web 静态原型
- `one-thought-star-river-miniprogram.zip`：可导入微信开发者工具的小程序包

## 小程序预览

1. 打开微信开发者工具。
2. 选择“导入项目”。
3. 项目目录选择本仓库根目录。
4. 正式上传前，将 `project.config.json` 中的 `appid` 替换成自己的小程序 AppID。

## 验证

```sh
node --check pages/index/index.js
```
