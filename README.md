# 一念星河 V0.1

治愈系宇宙卜卦小程序 MVP。

用户在深邃星空中轻触屏幕，触发星尘涟漪与聚拢动效，随后浮现一张“宇宙之卡”。卡片通过八卦、五行、天象、烦恼主题、答案倾向、签语和今日宜组合生成，提供温柔、诗意、非恐吓式的情绪陪伴。

## 项目内容

- app.wxss双击后，微信开发者工具自动导入，预览小程序

## 小程序预览

1. 打开微信开发者工具。
2. 选择“导入项目”。
3. 项目目录选择本仓库根目录。
4. 正式上传前，将 `project.config.json` 中的 `appid` 替换成自己的小程序 AppID。
